## 🧠 About

I started programming from scratch, and pretty quickly realized the interesting part isn't just getting code to run — it's understanding what's actually happening underneath: memory, execution, the machine.

That curiosity is what pulls me toward **C** and low-level programming, while I use **Python** and **Bash** to move fast, automate, and explore ideas.

- 🔭 Currently strengthening my fundamentals in **C, algorithms & memory management**
- 🌱 About to join **Epitech Lyon** to go deeper into software engineering
- ⚙️ Comfortable in a **Unix environment**, building my workflow around Git and the shell
- 💻 Daily driver: **MacBook M5 + VS Code**
- 🎯 Goal: build real things, break them, understand why, and rebuild them better
